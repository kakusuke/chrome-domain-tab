# Domain Tab Groups

Chrome のタブを登録可能ドメインごとにまとめる拡張機能です。

- **タブバー**: `google.com` のタブが2枚以上あれば `com.google` という名前のグループにまとめます。グループはドメインの逆順で並べ、グループ内はサブドメイン順（`api` → `www`）に並べます
- **サイドパネル**: 拡張アイコンをクリックすると、ドメインのツリーが開きます

```
▾ com.google        5
  ▾ api             2
      ...
  ▾ www             3
      ...
```

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ

## 挙動

- 自分で作ったタブグループには触りません。拡張が作ったグループと、グループに入っていないタブだけを整理します
- ピン留めタブと `chrome://` などの http(s) 以外のタブは対象外です
- 分割ビューの2枚は離さずに一緒に動かします。2枚が別サイトのときは左側のタブのサイトのグループに入れます
- 多段サフィックス（`co.jp` など）は `src/domain.js` の一覧で判定します。一覧にないものは最後の1ラベルをサフィックスとみなします
